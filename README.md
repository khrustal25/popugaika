# Попугайка 🦜

Интерактивный справочник для владельцев домашних попугаев.

**Слоган:** «Всё о твоём попугае — в одном месте»

Это обычный HTML-сайт. Его можно открыть на компьютере без установки программ и позже загрузить в репозиторий GitHub (в том числе для GitHub Pages).

> **Важно:** в этом репозитории — приложение «Попугайка», а не лендинг-портфолио. Ниже описано только то, что реально есть в проекте.

---

## Коротко о проекте

| | |
|---|---|
| **Что это** | Справочник по домашним попугаям: виды, питание, уход, поведение, здоровье, приручение и помощник «Перышко» |
| **Для кого** | Владельцы и новички, которым нужна понятная подсказка «в одном месте» |
| **Как устроен** | Одна страница (`index.html`) + стили + JavaScript; разделы открываются по адресу с `#/` |
| **Регистрация** | Не нужна |
| **Платные API** | Не подключены |

Материалы носят **справочный** характер и **не заменяют** консультацию ветеринара. Если проверенных данных нет, сайт честно пишет об этом.

---

## Какие разделы есть на сайте

- **Главная** — приветствие, кнопка выбора попугая, фото ары, карточки видов
- **Каталог / выбор вида** — 12 видов попугаев с фотографиями
- **Моя птичка** — раздел выбранного вида
- **Питание** — энциклопедия продуктов, поиск, категории, статусы «можно / с осторожностью / нельзя»
- **Уход и содержание** — клетка, купание, сон, игрушки, жердочки, прогулки, гигиена, климат, кормушки, первые дни дома
- **Поведение** — карточки поведения с поиском и пояснениями
- **Приручение** — уроки «Давай дружить!» с прогрессом по выбранному виду
- **Здоровье** — симптомы, статьи, срочная помощь, калькулятор изменения веса (только арифметика, не диагноз)
- **Перышко** — помощник на **локальной** базе знаний (это не нейросеть и не внешний AI)
- **Новичку** — чек-лист первых шагов
- **Справочник** — общее меню разделов ухода, поведения, здоровья и приручения

На телефоне есть нижнее меню: Главная, Моя птичка, Питание, Перышко, Справочник.

## Какие технологии используются

- **HTML5** — разметка
- **CSS3** — оформление и адаптив под телефон / планшет / компьютер
- **Vanilla JavaScript** — логика, переходы по `#/...`, работа с `localStorage`
- **Локальные файлы данных** в папке `data/` (обычные `.js`, без сервера)
- **Шрифты Manrope и Nunito** — подключаются с Google Fonts (нужен интернет)
- **Нет** React, Vue, TypeScript, Node.js, сборки и `npm install`

## Для чего нужны основные файлы и папки

```
index.html          — главная (и единственная) HTML-страница приложения
style.css           — все стили
script.js           — навигация, экраны, кнопки, сохранение выбора вида и прогресса
404.html            — для GitHub Pages: неизвестный адрес → возврат к index.html
.nojekyll           — чтобы GitHub Pages не обрабатывал сайт через Jekyll
README.md           — эта инструкция
.gitignore          — что не стоит случайно класть в Git (например .env)

data/               — база знаний (виды, еда, уход, поведение, здоровье, уроки, Перышко)
js/peryshko-ai.js   — поиск ответов Перышка по локальной базе
images/             — фото попугаев, иконки еды/ухода, favicon, аватар Перышка
scripts/            — вспомогательные скрипты генерации SVG (сайту для запуска не нужны)
```

## Как запустить проект локально

1. Откройте папку проекта на компьютере.
2. Найдите файл **`index.html`**.
3. Откройте его в браузере (двойной клик)  
   **или** через расширение вроде «Open with Live Server» в редакторе кода.

Готово: установка Node.js, `npm install` и сборка **не нужны**.

Данные подключены обычными тегами `<script>`, поэтому сайт работает и при открытии с диска.

**Совет:** если картинки или скрипты ведут себя странно при открытии «с диска», откройте ту же папку через Live Server — так ближе к тому, как сайт будет работать на GitHub Pages.

## Какие данные можно персонализировать

Менять можно **содержимое** (тексты, фото, списки), не трогая секреты — их в проекте нет.

| Что | Где править |
|-----|-------------|
| Виды попугаев, описания, пути к фото | `data/species.js` |
| Продукты и статусы безопасности | `data/foods.js` |
| Статьи ухода | `data/care.js` |
| Поведение | `data/behavior.js` |
| Здоровье, симптомы | `data/health.js` |
| Уроки приручения | `data/training.js` |
| Чек-лист новичка | `data/beginner.js` |
| Подсказки / база Перышка | `data/peryshko-knowledge.js`, `data/chat.js` |
| Имя и подписи Перышка (без API-ключей) | `data/ai-config.js` |
| Фото и иконки | папка `images/` |
| Цвета, отступы, адаптив | `style.css` |
| Заголовок вкладки и описание сайта | `index.html` (теги `<title>`, `description`) |

В браузере у пользователя сохраняются (в `localStorage`): выбранный вид, история Перышка, прогресс уроков и чек-листа новичка. Это данные на устройстве пользователя, не пароли и не ключи проекта.

**Не добавляйте** в файлы проекта пароли, токены и ключи API. Перышко работает без внешних AI-сервисов.

## Как пользоваться (кратко)

1. На главной нажмите **«Выбрать попугая»** или карточку вида.
2. Откройте питание, уход, поведение, здоровье или приручение — подсказки учитывают выбранный вид.
3. В **Питании** поищите продукт, например «Яблоко».
4. В **Перышке** задайте вопрос из примеров или свой — ответ берётся из локальной базы.
5. Если ответа нет, помощник честно об этом сообщит.

## Подготовка к загрузке в GitHub (ещё не публикация)

Сейчас проект только **готовится** к загрузке в репозиторий. Ниже — как позже выложить файлы через браузер и при желании включить GitHub Pages.

### 1. Создать репозиторий

1. Зайдите на [https://github.com](https://github.com).
2. Создайте новый репозиторий (например `popugaika`), тип **Public**.
3. Галочку «Add a README» можно не ставить — README уже есть в проекте.

### 2. Загрузить файлы через браузер

1. На странице репозитория выберите загрузку файлов (**uploading an existing file**).
2. Перетащите нужные файлы и папки:
   - обязательно: `index.html`, `404.html`, `.nojekyll`, `style.css`, `script.js`
   - папки: `data`, `js`, `images`
   - по желанию: `README.md`, `.gitignore`
3. Нажмите **Commit changes**.

Папку `scripts/` для работы сайта загружать не обязательно.

### 3. (Позже) Включить GitHub Pages

1. **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` (или `master`), папка `/ (root)` → **Save**
4. Через несколько минут сайт обычно доступен по адресу вида:

```text
https://ВАШ_НИК.github.io/ИМЯ_РЕПОЗИТОРИЯ/
```

### Важно для GitHub Pages

- Навигация через `#/nutrition`, `#/chat` и т.п. — обновление страницы не должно ломать сайт
- `.nojekyll` нужен, чтобы GitHub не «ломал» обычные HTML-файлы
- `404.html` возвращает на главную при неизвестном пути
- Не кладите в репозиторий секретные ключи и платные API
